# Article 65

Les électeurs nomades votent dans les circonscriptions électorales où ils se trouvent en ce qui concerne les consultations référendaires et présidentielles.

Pour les consultations législatives, ils votent dans les bureaux de vote préalablement définis pour le compte de leurs circonscriptions électorales d’origine.
