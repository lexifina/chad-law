# Article 218

La désinfection, la dératisation, la désinsectisation sont obligatoires dans les hôtels, les restaurants, les auberges, les gargotes, les cafétérias, les débits de boisson, les entrepôts, les industries, les établissements aéroportuaires.

Ces opérations sont payantes et prises en charge par les exploitants.

Elles peuvent se faire dans les habitations à la demande des intéressés.
