# Article 11

II est interdit de jeter ou d’enfouir les cadavres d’animaux, les ordures ménagères, les pierres, les graviers, le bois sur les voies et places publiques, sur les rives ou dans les mares, les rivières, les fleuves, les lacs, les étangs, les bassins de rétention, les barrages, les lagunes et les caniveaux, ou à proximité d’un point d’eau.
