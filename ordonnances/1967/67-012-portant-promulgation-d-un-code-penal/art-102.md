# Article 102

Toute provocation directe à un attroupement armé sera punie, d’un emprisonnement de un an à cinq ans, si elle a été suivie d’effet et, dans le cas contraire, d’un emprisonnement de trois mois à un an.

Toute provocation directe à un attroupement non armé sera punie, de trois mois à un an d’emprisonnement, si elle a été suivie d’effet et, dans le cas contraire, d’un emprisonnement d’un à six mois.
