# Article 155

Les fautes d’orthographe, les simples erreurs matérielles qui peuvent se trouver dans un jugement, doivent toujours être rectifiées, même d’office, par le tribunal.

Il est statué sur les rectifications sans débat oral préalable. La décision qui ordonne une rectification est mentionnée sur la minute et les expéditions des jugements.
