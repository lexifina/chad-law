# Article 295

Lorsque, sur une plainte visant une personne dénommée avec constitution de partie civile, une information a été ouverte puis clôturée par une ordonnance de non-lieu, la personne visée dans la plainte peut demander des dommages-intérêts à la partie civile, sans préjudice d’une poursuite pénale pour dénonciation calomnieuse.

La demande peut être portée, soit devant le tribunal correctionnel, soit devant le tribunal civil. Dans les deux cas, l’action doit être introduite avant l’expiration d’un délai de trois mois, à compter du jour où l’ordonnance de non-lieu est devenue définitive.

Le demandeur porte son action devant le tribunal correctionnel ; elle est introduite par voie de citation devant le tribunal où l’affaire a été instruite.
