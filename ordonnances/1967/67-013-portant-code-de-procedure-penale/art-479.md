# Article 479

Un décret détermine l’organisation et le régime intérieur des établissements pénitentiaires.

Il détermine également les conditions de répartition des condamnés entre les différents établissements pénitentiaires, les modalités d’exécution des diverses peines privatives de liberté prévues par le Code pénal, le régime auquel doivent être soumis les condamnés.
