# Article premier

Il est créé un Commissariat de Sécurité Publique dans les Chefs-Lieux des Départements ci-après :

DABARA : BOKORO

BAGUIRMI : MASSENYA

BATHA-EST : OUM-HADJER

BILTINE : BILTINE

BORKOU : FAYA

ENNEDI : FADA

GUERA : MONGO

HADJER-LAMIS : MASSAGUET et MASSAKORY

KABIA : GOUNOU-GAYA

KANEM : MAO

LAC : BOL

LAC IRO : KYABE

ASSONGHA : ADRE

MONTS DE LAM : MBAIBOKOUM

SILA : GOZ-BEIDA

SALAMAT : AM-TIMAN.
