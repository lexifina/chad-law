# Article premier

- Le montant de l’amende de composition est fixé comme suit :

500 francs pour les contraventions prévues à l’article 349 du code pénal, numéros : 2, 6, 19, 22, 23, 26, 30 ;

1 000 francs pour les contraventions prévues à l’article 349 du code pénal, numéros : 7, 8, 9, 13, 14, 24, 27, 29;

2 000 francs pour les contraventions prévues à l’article 349 du code pénal, numéros: 3, 4, 5, 10, 11, 12, 15, 16, 17, 18, 20, 21, 25, 28.
