# Article premier

Les cantons ci-dessous cités de la région du Sila sont restructurés ainsi qu’il suit :

1-DEPARTEMENT DE KIMITI

Sous-préfecture de Tissi

Le Canton FONGORO est restructuré comme suit:

Canton FONGORO, chef-lieu : Haraza ;

Canton TISSI, chef lieu : Tissi.

Sous-préfecture de Moudeina

Le Canton OUADI KADJA est restructuré comme suit :

Canton OUADI KADJA 1, chef-lieu : Moudeina ;

Canton OUADI KADJKA II, chef-lieu : Dornon

Sous-préfecture Goz-Beïda

Les Cantons OUADI HABILE et KADJASKE sont restructurés comme suit :

Canton OUADI HABILE I, chef-lieu: Doroti ;

Caton OUADI HABILE II, chef-lieu : Fagatar ;

Canton KADJASKE I, chef-lieu : Echbara ;

Canton KADJASKE II, Chef-lieu: Beïda.

Sous-préfecture de Koukou Angarana

Le canton BARH AZOUM est restructuré comme suit :

Canton BARH AZOUM, chef-lieu: Koukou Angarana ;

Canton KHACH KACHA, chef-lieu : Tiéro.

Sous-préfecture d’Adé

Le Canton KOLOI est restructuré comme suit:

Canton KOLOI, chef-lieu: Adé ;

Canton KOUMOU, chef-lieu: Koumou.

2-DEPARTEMENT DE DJOUROUF-AL AHMAR

Sous-préfecture de Magrane

Le canton MASSALAT est restructuré ainsi qu’il suit :

Canton MASSALAT I, chef-lieu: Idalbagar ;

Canton MASSALAT II, chef-Heu : Moura.
