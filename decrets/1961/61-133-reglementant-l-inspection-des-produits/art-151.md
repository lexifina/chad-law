# Article 151

— Seront saisis, détruits ou dénaturés, les poissons frais présentant les maladies parasitaires suivantes :

Psoraspermoses ;

Épithélioma, variole ou petite vérole des poissons d’élevage ;

Ichthyophtiriase ;

Champignons (saprologuiées) ;

Ladrerie ;

Ligulose ;

Diplostomiasis ;

Éthinorhynques.
