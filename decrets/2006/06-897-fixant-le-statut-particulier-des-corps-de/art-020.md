# Article 20

Le Cadre des Relations Presse et Relations Publiques comprend les corps indiqués dans le tableau indiqués ci-après, qui en précise également les conditions d’accès par voies externe et interne.

| | Corps des Relations Presse et Relations Publiques | | | |

| Intitulé du corps | Classif | Accès au corps par voie externe | | Accès par la voie interne

| Diplômes académiques | Formation professionnelle | | |

| Expert en Communication | A3 | Pas d’accès par voie externe | | Ouvert aux Conseiller en Communication sur concours après 5 ans de service effectif

| | | | |

| Conseiller en Communication | A2 | BAC | +4 ou 5 ans d’études sanctionnées par une maîtrise, un DEA ou un DESS en sciences et recherche de l’information | Ouverts aux Assistants en Communication sur concours après 5 ans de service effectif

| | | | |

| Assistant en Communication | A1 | BAC | +3 ans de formation théorique et pratique à l’Université de N’Djaména ou toute autre institution similaire |
