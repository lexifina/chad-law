# Article premier

Le prix du nouveau Passeport Ordinaire Sécurisé est fixé comme suit :

85.300 F CFA (quatre vingt cinq mille trois cents francs CFA) pour les Tchadiens adultes de l’intérieur du pays ;

42.500 F CFA (quarante deux mille cinq cents francs CFA) pour les Tchadiens mineurs à l’intérieur du pays ;

160 (cent soixante euros) pour les Tchadiens adultes résidant à l’Étranger ;

80 (quatre vingt euros) pour les Tchadiens mineurs résidant à l’Étranger.
