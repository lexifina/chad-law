# Article 14

Le Cadre de l’Élevage comprend les corps indiqués dans le tableau ci-après, qui en précise également les conditions d’accès par voies externe et interne.

| Diplôme académique | Formation professionnelle | | |

| | | | |

| Médecin Vétérinaire | A2 | BAC | +5 ans de formation au moins à l’Ecole d’Ingénieur de Montpellier (France) ou toute autre institution de formation similaire | Pas d’accès par voie interne
