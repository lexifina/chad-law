# Article 8

Placé sous l’autorité directe du directeur des études, l’organe technique d’encadrement regroupe tout le corps enseignant.

Il comprend :

Transmissions ;

Topographie ;

Combat ;

Santé ;

Auto ;

Civisme ;

Enseignement général (mathématiques-histoire-géographie-lettres) ;

Langues (anglais-arabes).
