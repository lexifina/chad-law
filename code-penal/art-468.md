# Article 468
Une personne qui commet une infraction de presse, notamment une diffamation, une injure publique, une apologie de crime, par le biais d'un moyen de communication électronique public, commet une infraction punissable des mêmes peines que celles prévues pour les infractions de presse commises par d'autres moyens.
