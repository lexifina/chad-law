# Article 28
Les peines complémentaires sont :
l'interdiction de séjour :
l'interdiction du territoire ;
l'interdiction de certains droits ;
la confiscation de certains biens ;
la fermeture d'un établissement ;
l'interdiction d'exercer une profession ou une activité ;
la publicité de la condamnation.
Hors les cas où le prononcé d'une peine complémentaire est obligatoire pour le juge, toute décision devra comporter l'exposé des motifs qui justifient le prononcé d'une peine complémentaire.
Les peines complémentaires peuvent se cumuler, sauf incompatibilité. Les difficultés d'exécution sont soumises par le Ministère public à la juridiction qui a prononcé la dernière condamnation.
