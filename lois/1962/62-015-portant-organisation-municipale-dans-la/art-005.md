# Article 5

Le nombre des conseillers municipaux à élire dans chaque commune est fixé comme suit :

11 membres dans les communes de 500 habitants et au-dessous ;

13 membres dans les communes de 501 à 2.500 habitants ;

17 membres dans les communes de 2.501 à 3.500 habitants ;

21 membres dans les communes de 3.501 à 6.000 habitants ;

23 membres dans les communes de 6.001 à 8.000 habitants ;

25 membres dans les communes de 8.001 à 10.000 habitants;

27 membres dans les communes de 10.001 à 20.000 habitants ;

29 membres dans les communes de 20.001 à 30.000 habitants ;

31 membres dans les communes de 30.001 à 40.000 habitants ;

33 membres dans les communes de 40.001 à 50.000 habitants ;

35 membres dans les communes de 50.001 à 60.000 habitants ;

37 membres dans les communes de 60.001 habitants et au-dessus.
