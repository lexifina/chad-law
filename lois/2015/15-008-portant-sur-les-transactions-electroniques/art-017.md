# Article 17

Toute exigence légale ou réglementaire de forme est réputée satisfaite lorsque les qualités fonctionnelles de cette exigence ont été préservées.

Pour l’application du présent article, il est tenu compte du contexte et de l’objet de l’information à laquelle s’appliquent les exigences de forme, ainsi que de toutes les circonstances y ayant trait.

Pour l’application de l’alinéa 1 du présent article, il y a lieu de considérer que :

l’exigence d’une signature est satisfaite dans les conditions prévues à l’article 20 ;

l’exigence d’un écrit est satisfaite dans les conditions prévues à l’article 25 ;

l’exigence d’un original est satisfaite dans les conditions prévues à l’article 28 ;

l’exigence d’exemplaires multiples est satisfaite dans les conditions prévues à l’article 34 ;

l’exigence d’une mention manuscrite est satisfaite dans les conditions prévues à l’article 31, l’exigence d’un recommandé est satisfaite dans les conditions prévues à l’article 35 ;

l’exigence d’une facture est satisfaite dans les conditions prévues à l’article 38.
