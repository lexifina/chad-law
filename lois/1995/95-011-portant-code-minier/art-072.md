# Article 72

Infrastructures

Les titulaires d’un permis d’exploitation ou bénéficiaires d’une autorisation d’exploitation en vertu du Code Minier peuvent construire ou faire construire les infrastructures nécessaires à leurs activités en vertu du Code Minier, sous réserve de leur approbation par l’Etat si elles peuvent servir à d’autres usagers ou encore si l’Etat y participe.
