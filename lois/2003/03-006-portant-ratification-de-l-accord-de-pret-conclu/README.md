# Loi n° 03-006 du 7 mai 2003

Loi portant ratification de l'accord de prêt conclu le 23 octobre 2002 entre la République du Tchad et la Banque Islamique de Développement (BID) pour le financement du projet de construction de 20 centres de santé dans le Biltine
