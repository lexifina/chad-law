# Article 3

On distingue huit espèces de congé :

Les congés administratifs de dépaysement ou territorial ;

Les congés de maladie ;

Les congés de longue durée ;

Les congés de convalescence ou de cure thermale ;

Les congés pour affaires personnelles ;

Le congé pour examen ;

Le congé d’expectative de réintégration ;

Le congé de maternité.
