# Article 126

La création d’un aérodrome par une personne autre que l’Etat est subordonnée à une autorisation administrative délivrée dans les conditions fixées par le présent Code et ses textes d’application. Toutefois, lorsque l’aérodrome fait l’objet d’une convention, d’un décret déclaratif d’utilité publique pris en vue de recourir à la procédure d’expropriation, ou un décret de classement, ces actes tiennent lieu d’autorisation.
