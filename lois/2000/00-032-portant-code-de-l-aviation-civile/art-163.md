# Article 163

Les dispositions du présent Code relatives aux redevances pour services rendus aux usagers sur les aérodromes ouverts à la circulation aérienne publique sont applicables de plein droit sur les aérodromes agréés à usage restreint réserve faite des cas où la convention passée entre l’Etat et la personne qui a créé l’aérodrome prévoit des dispositions contraires.
