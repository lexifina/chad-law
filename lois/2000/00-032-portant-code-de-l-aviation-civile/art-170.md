# Article 170

Lorsque, pour les besoins du trafic aérien, l’autorité compétente décide l’extension ou la création d’aérodromes ou d’installations destinées à assurer la sécurité de la navigation aérienne, les terrains nécessaires, s’ils n’ont pas été réservés à cette destination, peuvent être déclarés réservés dans les formes fixées par le Code de l’Expropriation pour cause d’utilité publique.
