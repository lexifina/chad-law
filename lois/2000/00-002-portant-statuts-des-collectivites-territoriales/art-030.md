# Article 30

Le Conseil Départemental se compose de :

11 membres pour les Départements à partir de 10.000 habitants ;

15 membres pour les Départements de 10.001 à 50.000 habitants

21 membres pour les Départements de 50.001 à 100.000 habitants ;

25 membres pour les Départements de 100.001 à 150.000 habitants ;

31membres pour les Départements de 150.001 à 250.000 habitants ;

35 membres pour les Départements de 250.001 à 350.000 habitants ;

39 membres pour les Départements de 350.001 habitants et plus.
