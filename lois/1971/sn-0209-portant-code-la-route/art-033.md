# Article 33

Dans les agglomérations, seuls peuvent être employés les avertisseurs sonores pour l’usage urbain tels qu’ils sont prévus à l’article 96 du présent code. Les signaux émis doivent être brefs et leur usage très modéré.

Entre la chute et le lever du jour, les avertissements doivent être donnés par signal optique à l’aide des feux de croisement, les signaux sonores ne doivent être utilisés qu’en cas d’absolue nécessité.
