# Article 184

Le candidat qui s’est vu opposer un refus d’enregistrement dispose de quarante huit (48) heures pour saisir le tribunal de 1ère Instance qui statue dans les trois (3) jours.

Faute pour le tribunal d’avoir statué dans ce délai, la candidature doit être enregistrée.
