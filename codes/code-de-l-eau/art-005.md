# Article 5

Les droits d'occupation existant sur le domaine public naturel de l'État à la date d'entrée en vigueur du présent code peuvent être compensés en droit d'usage portant sur un espace de plan d'eau ou un volume équivalent aux droits de propriété.
Ces droits n'excluent pas pour autant le droit de domanialité de l'État qui prédomine.
