# Article 58

La demande d’autorisation de prospection doit étre accompagnée d’un dossier dont le détail est précisé par voie réglementaire et comprenant impérativement, entre autres, chacun des éléments suivants :
(i) une identification compléte du requérant ;
(ii) les substances minérales pour lesquelles l’autorisation de prospection est sollicitée ;
(iii) un programme général des travaux envisagés pour la durée de validité de Yautorisation de prospection.
