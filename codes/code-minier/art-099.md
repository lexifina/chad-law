# Article 99

Inhabilité pour l’Obtention d’un Titre Minier Les individus condamnés à une peine d’emprisonnement pour infraction au Code Minier ne peuvent obtenir un titre minier ou une autorisation en vertu du Code Pénal. Toutefois, les titres miniers ou autorisations dont ils sont titulaires ou bénéficiaires au moment de leur condamnation et qui n’ont pas fait l’objet d’un retrait en vertu du Code Minier peuvent être renouvelés.
