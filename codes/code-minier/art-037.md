# Article 37

: Les activités miniéres ne peuvent étre exercées qu’en vertu des autorisations et titres miniers ci-aprés :
(i) | autorisation de prospection ;
(ii) | permis de recherche miniére ;
(iii) permis d’exploitation semi-industrielle ;
(iv) permis d’exploitation miniére industrielle ;
(v) autorisation d’exploitation des rejets ;
(vi) autorisation d’exploitation de carriére artisanale ;
(vii) autorisation d’exploitation industrielle de carriére temporaire ;
(viii) autorisation d’exploitation industrielle de carriére permanente ;
(ix) autorisation d’exploitation artisanale.
