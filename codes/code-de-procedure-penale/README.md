# Loi n° 012/PR/2017 du 14 juillet 2017 portant Code de procédure pénale

- Source : édition 2018 du Ministère de la Justice, chargé des Droits humains (PDF natif), copie tenue par la Criminal Justice in Africa Database (CJAD, Université de Nottingham), <https://cjad.nottingham.ac.uk/en/legislation/648/>
- Fichier : <https://cjad.nottingham.ac.uk/documents/implementations/pdf/Chad-Criminal_Procedure_Code_2017_FR.pdf>
- Promulgation : 14 juillet 2017 (« Fait à N’Djaména, le 14 juillet 2017 ») ; adoptée par l’Assemblée nationale le 20 décembre 2016.
- Entrée en vigueur : 1er octobre 2017, l’article 691 rendant le code applicable « le premier jour du troisième mois qui suivra sa promulgation ».
- Unités : 694 articles (de l’article 1 à l’article 694).
- Version : texte d’origine ; les modifications ultérieures ne sont pas appliquées. Les intitulés des livres, titres, chapitres et sections sont omis.
