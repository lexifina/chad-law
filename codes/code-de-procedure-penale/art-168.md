# Article 168

Le juge d'instruction peut ordonner à toute personne connaissant le fonctionnement du système informatique ou les mesures appliquées pour protéger les données informatiques qu'il contient de fournir toutes les informations raisonnablement nécessaires pour permettre l'application des mesures prévues par les articles 162 et 163 du présent Code.
