# Article 127

Seules les eaux de sources dont l'exploitation a été autorisée peuvent être vendues sous l'appellation « eau de source naturelle » ou « eau minérale» ou «eau gazeuse». L'étiquetage des eaux naturelles, minérales ou gazeuses, mises en vente, doit comporter les mentions suivantes : le nom de la source ;
l'indication du lieu d'exploitation ;
l'inscription d'une mention se rapportant à la composition, en énumérant les éléments caractéristiques déterminés par une analyse officiellement reconnue ;
le numéro d'autorisation administrative ;
le numéro de lot ;
