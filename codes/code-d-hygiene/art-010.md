# Article 10

Les dépôts de déchets (immondices, détritus, ferrailles, épaves, fûts usés, décombres, gravats, ordures, etc..) sont interdits sur les voies et places publiques, sur les rives ou dans les mares, les rivières, les fleuves, les lacs, les étangs, les canaux d'évacuation des eaux pluviales, les bassins collecteurs des eaux pluviales, les canaux d'irrigation, les barrages et à proximité d'un point d'eau.
