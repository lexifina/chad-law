# Article 20

Béton armé

Suivant le type de bâtiment, seront réalisés en béton armé : l’ossature qui comprend en principe :

les semelles de fondations ;

les poteaux en fondations ;

les longrines formant soubassements ;

les poteaux en élévation ;

les poutres ;

les chaînages ou linteaux chaînages.

Les ouvrages divers :

les linteaux ;

les auvents ;

les paillasses d’office ou de cuisine ;

les dalles de couverture des fosses septiques, puisards,

regards, etc…

le couronnement des murs non protégés par la couvertu­re ou une étanchéïté.

Dans la mise en œuvre du béton armé, on devra réserver les trous pour scellement des pièces de charpente ou de menui­serie et, d’une manière générale, prendre toutes dispositions pour éviter les refouillements ultérieurs dans la masse du béton.
