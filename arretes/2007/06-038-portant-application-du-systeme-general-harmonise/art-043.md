# Article 43

Les substances et mélanges sont classés en fonction du danger qu’ils peuvent présenter pour la santé, dans une ou plusieurs des sept (07) classes ci-après:

Classe 1: toxicité aiguë ;

Classe 2: irritation /corrosion oculaire ;

Classe 3: irritation /corrosion cutanée ;

Classe 4: sensibilisation respiratoire ou cutanée ;

Classe 5: pouvoir mutagène sur les cellules germinales ;

Classe 6: toxicité pour la reproduction ;

Classe 7: toxicité systémique pour certains organes cibles.
