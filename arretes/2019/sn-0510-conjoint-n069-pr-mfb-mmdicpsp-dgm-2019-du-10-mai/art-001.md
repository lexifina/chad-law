# Article premier

Sont exonérés des Droits de Douanes de la Taxe sur la Valeur Ajoutée, les produits de première nécessité, conformément au tableau ci-après :

| | | | | |

| Nature du produit | Droits de Douanes | | Taxe sur la Valeur Ajoutée |

| | Ancien taux | Nouveaux taux | Ancien taux | Nouveaux taux

| Riz | 5 % | 0 % | 0 | 0 %

| Farine | 5 % | 0 % | 0 | 0 %

| Huile | 30 % | 0 % | 18 % | 0 %

| Pates alimentaires | 30 % | 0 % | 18 % | 0 %
