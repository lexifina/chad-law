# Article 3

Le comité technique interministériel est chargé de :

identifier de manière exhaustive les activités réglementées et d’établir une liste,

étudier et de préciser les conditions d’exercice dans le cas d’une création, d’une reprise, d’une extension d’entreprise ou d’une ouverture de succursale ou de filiale, pour chacune des activités réglementées,

définir la forme du document portant précision sur 1’ activité (ou les activités) pour laquelle (lesquelles) l’autorisation d’exercer est accordée ;

identifier la personne habilitée à signer ’ agrément,

produire un texte réglementaire régissant les conditions d’exercice dans le cas d’une création, d’une reprise, d’une extension d’entreprise ou d’une ouverture de succursale ou de filiale pour chaque activité ré9lementée.
